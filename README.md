# Student Management System

A simple Student Management System built using Java Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

- Add new student
- View all students
- Search students by name and roll number
- Update student details
- Delete student records
- Form validation
- Responsive frontend design

## Technologies Used

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Java
- Spring Boot
- Spring Data JPA
- Maven

**Database**
- MySQL

## Setup Instructions

1. Clone or download this repository.
2. Open the backend project in IntelliJ IDEA.
3. Create a MySQL database named `studentManagement_system`.
4. Configure your database credentials in `application.properties`.
5. Run the Spring Boot application.
6. Open `frontend/index.html` using VS Code Live Server.
